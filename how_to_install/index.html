คู่มือติดตั้งและตั้งค่า Fastwork Bot

ขั้นตอนการติดตั้งระบบบอทตรวจจับงานและยื่นเสนออัตโนมัติ 100% ตั้งแต่การติดตั้ง Python จนถึงการเริ่มเปิดระบบทำงาน

1

ติดตั้งโปรแกรม Python (ครั้งแรกครั้งเดียว)

หากในเครื่องของคุณมี Python อยู่แล้ว สามารถข้ามไปขั้นตอนที่ 2 ได้เลย

1. ดาวน์โหลดโปรแกรม Python 3.10 หรือใหม่กว่า ได้ที่เว็บไซต์ทางการ: python.org/downloads

2. ดับเบิลคลิกไฟล์ติดตั้ง Python ที่ดาวน์โหลดมา

⚠️
จุดสำคัญที่สุด (ห้ามลืมเด็ดขาด!):
ในหน้าแรกของตัวติดตั้ง ให้ ติ๊กถูกที่ช่อง [ ✔ ] Add Python.exe to PATH ที่อยู่ด้านล่างสุดก่อน แล้วค่อยกด Install Now

1. ดาวน์โหลด Python สำหรับ macOS ได้ที่: python.org/downloads/macos

2. เปิดไฟล์ .pkg แล้วกด Continue / Install ตามขั้นตอนจนเสร็จสิ้น

2

ติดตั้ง Library เสริม (Dependencies)

เปิด Command Prompt หรือ Terminal เพื่อติดตั้งโมดูลที่บอทต้องใช้

คัดลอกคำสั่งด้านล่างนี้ไปวางใน Command Prompt (Windows) หรือ Terminal (Mac) แล้วกด Enter:

pip install requests pillow pystray plyer psutil playwright && playwright install chromium
✅
คำสั่งนี้จะติดตั้งระบบแจ้งเตือน Desktop, ระบบ GUI, และ Browser Chromium สำหรับดึงคุกกี้ Token อัตโนมัติให้ครบถ้วนในคำสั่งเดียว
3

4

ล็อกอิน Fastwork เพื่อดึง Token และสินค้าอัตโนมัติ

เชื่อมต่อกับบัญชี Fastwork ของคุณใน 1 คลิก ไม่ต้องกรอก Token เอง

1. ในหน้าต่างตั้งค่า แท็บแรก "🔑 บัญชี & คุกกี้ Token" ให้กดปุ่มสีฟ้า:

🎯 ปุ่มกดดึง Token อัตโนมัติ:

2. ระบบจะเปิดหน้าเว็บ fastwork.co ขึ้นมา ให้คุณทำการ เข้าสู่ระบบ (Login) ด้วยบัญชี Fastwork ของคุณตามปกติ

3. เมื่อเข้าสู่ระบบเสร็จสิ้น ระบบบอทจะ ดักจับ Token + ดึงรายการสินค้าทั้งหมดของคุณ มาบันทึกให้อัตโนมัติทันที!

5

ตั้งค่าคีย์เวิร์ด และใบเสนอราคา

กำหนดประเภทงานที่ต้องการรับ ราคา และข้อความที่จะตอบกลับผู้ว่าจ้าง

🎯 1. แท็บ "คีย์เวิร์ดหางาน"

ใส่คำที่ต้องการให้บอทตรวจจับ (1 บรรทัดต่อ 1 คำ) เช่น:

ตัดต่อรูปภาพ
แก้ไขเอกสาร
photoshop

✍️ 2. แท็บ "ใบเสนองาน"

ใส่ข้อความแนะนำตัวและบริการของคุณ (ความยาวอย่างน้อย 100 ตัวอักษร) พร้อมกำหนดราคางบประมาณเริ่มต้นและจำนวนวันทำงาน

📎 3. แท็บ "ไฟล์ผลงาน PDF"

นำไฟล์ PDF ผลงาน หรือ รูปภาพตัวอย่างงาน มาวางไว้ในโฟลเดอร์ portfolio/ บอทจะแนบให้ผู้ว่าจ้างดูอัตโนมัติทุกครั้งที่ยื่นงาน
