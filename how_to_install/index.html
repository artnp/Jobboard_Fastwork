ขั้นตอนเริ่มต้น: แตกไฟล์ ZIP โปรแกรม (Unzip)

นำไฟล์โปรแกรมออกจากไฟล์บีบอัด .zip ก่อนเริ่มต้นใช้งาน

🗜️ วิธีแตกไฟล์บน Windows:

1. ไปที่ไฟล์ที่ดาวน์โหลดมา เช่น Jobboard_Fastwork-main.zip หรือ Jobboard_Fastwork.zip

2. คลิกขวาที่ไฟล์ .zip ➔ เลือกเมนู "Extract All..." (แตกไฟล์ทั้งหมด...)

3. จะมีหน้าต่างขึ้นมา ให้กดปุ่ม Extract

4. คุณจะได้โฟลเดอร์สีเหลืองปกติชื่อ Jobboard_Fastwork ให้ ดับเบิลคลิกเข้าไปในโฟลเดอร์นี้ เพื่อเริ่มทำขั้นตอนถัดไป

⚠️
ข้อควรระวัง: ห้ามดับเบิลคลิกรันไฟล์ขณะที่ยังอยู่ในไฟล์ .zip โดยเด็ดขาด เพราะ Windows จะมองเป็นไฟล์อ่านอย่างเดียวและไม่สามารถบันทึกการตั้งค่าได้ ต้องแตกไฟล์ (Extract) ออกมาเป็นโฟลเดอร์ปกติก่อนเสมอนะครับ
🍏 วิธีแตกไฟล์บน macOS:

1. ดับเบิลคลิกที่ไฟล์ Jobboard_Fastwork.zip

2. ระบบ Mac จะแตกไฟล์ออกมาเป็นโฟลเดอร์ปกติให้เองอัตโนมัติทันที

3. ดับเบิลคลิกเข้าไปในโฟลเดอร์เพื่อเริ่มทำขั้นตอนถัดไป

🌟 วิธีที่ 2.1 (ง่ายที่สุด - แนะนำสำหรับมือใหม่)

← ดับเบิลคลิกไฟล์นี้

หน้าต่างสีดำจะเปิดขึ้นมาและติดตั้งทุกอย่างให้เองอัตโนมัติ เมื่อเสร็จจะมีข้อความแจ้ง ให้กด Enter เพื่อปิดได้เลยครับ

⌨️ 1. เปิดหน้าต่าง Command Prompt

กดปุ่ม Windows + R บนคีย์บอร์ดพร้อมกัน

🪟 หน้าต่าง Run

พิมพ์คำว่า cmd ในช่อง:

แล้วกดปุ่ม Enter หรือคลิก OK

📋 2. วางคำสั่งติดตั้ง

กดปุ่มคัดลอกคำสั่งด้านล่างนี้:

pip install requests pillow pystray plyer psutil playwright && playwright install chromium

จากนั้นสลับไปที่หน้าต่างสีดำ (Command Prompt) คลิกขวา 1 ครั้ง (หรือกด Ctrl + V) เพื่อวางคำสั่ง แล้วกดปุ่ม Enter

🍏 วิธีติดตั้งสำหรับ Mac

ดับเบิลคลิกไฟล์ ติดตั้งระบบ_Install.command ในโฟลเดอร์ หรือเปิด Terminal แล้ววางคำสั่งนี้:

pip3 install requests pillow pystray plyer psutil playwright && python3 -m playwright install chromium
✅
เมื่อติดตั้งเสร็จสิ้น: หน้าต่างสีดำจะหยุดวิ่งและขึ้นบรรทัดใหม่ แปลว่าติดตั้งระบบสมบูรณ์พร้อมใช้งานแล้วครับ!

ขั้นตอนที่ 4: ล็อกอิน Fastwork เพื่อดึง Token & สินค้า

เชื่อมต่อกับบัญชี Fastwork อัตโนมัติในคลิกเดียว ไม่ต้องกรอก Token เอง

🌐 4.1 กดปุ่มดึง Token อัตโนมัติ

ในหน้าต่างตั้งค่า แท็บแรก "🔑 บัญชี & คุกกี้ Token" ให้คลิกที่ปุ่มสีฟ้า:

🔑 4.2 ทำการเข้าสู่ระบบบนเว็บ Fastwork

หน้าต่างเบราว์เซอร์จะเปิดขึ้นมา ให้คุณกรอกอีเมลและรหัสผ่านเพื่อ เข้าสู่ระบบ (Login) Fastwork ตามปกติ

🎉 4.3 ระบบบันทึกให้อัตโนมัติ

เมื่อล็อกอินผ่านแล้ว ระบบจะ ดักจับ Token + ดึงรายการสินค้าทั้งหมดของคุณ มาบันทึกลงโปรแกรมให้ทันทีใน 1-2 วินาที โดยไม่ต้องกดอะไรเพิ่มอีกเลยครับ!

ขั้นตอนที่ 5: ตั้งค่าคีย์เวิร์ด และใบเสนอราคา

กำหนดประเภทงานที่ต้องการรับ ราคา และข้อความที่จะตอบกลับผู้ว่าจ้าง

🎯 1. แท็บ "คีย์เวิร์ดหางาน"

พิมพ์คำที่ต้องการให้บอทตรวจจับ (1 บรรทัดต่อ 1 คำ) เช่น:

ตัดต่อรูปภาพ
แก้ไขเอกสาร
photoshop

✍️ 2. แท็บ "ใบเสนองาน"

พิมพ์ข้อความแนะนำตัวและบริการของคุณ (ความยาวอย่างน้อย 100 ตัวอักษร) พร้อมกำหนดราคางบประมาณเริ่มต้นและจำนวนวันทำงาน

📎 3. แท็บ "ไฟล์ผลงาน PDF"

นำไฟล์ PDF ผลงาน หรือ รูปภาพตัวอย่างงาน มาวางไว้ในโฟลเดอร์ portfolio/ บอทจะแนบให้ผู้ว่าจ้างดูอัตโนมัติทุกครั้งที่ยื่นงาน
